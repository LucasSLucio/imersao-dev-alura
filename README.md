## 💡 Sobre o Projeto

O **Guia de Primeiros Socorros |  é uma aplicação web desenvolvida para fornecer informações rápidas e precisas sobre procedimentos essenciais de primeiros socorros.

Em situações de emergência, o tempo de resposta é crucial. Este guia permite que o usuário **busque por palavra-chave** ou **filtre por categoria** para encontrar imediatamente as instruções de ação (o que fazer) e os contatos de emergência (SAMU e Bombeiros).

O projeto foi desenvolvido durante a **Imersão dev Alura** e aperfeiçoado conforme escolhido.

## ✨ Funcionalidades Principais

* **Busca Instantânea:** Pesquisa por nome, descrição ou tags (palavras-chave).
* **Filtro por Categoria:** Organização e filtragem dos cards por tipo de emergência (ex: Queimaduras, Afogamento).
* **Layout Adaptativo (Home/Resultado):** Alterna automaticamente entre a tela inicial centralizada e a tela de resultados com cabeçalho fixo.
* **Modal Interativo:** Exibe instruções detalhadas, links para fontes oficiais (Saiba Mais), vídeos relacionados e botões de chamada rápida (`tel:`) e cópia do número.
* **Responsividade:** Design otimizado para visualização em desktops e dispositivos móveis.

## 💻 Tecnologias Utilizadas

* **HTML5:** Estrutura semântica.
* **CSS3:** Estilização moderna (Dark Theme) e uso de variáveis CSS para paleta de cores.
* **JavaScript (Puro):** Lógica de busca, filtragem de dados e manipulação do DOM.
* **JSON:** Base de dados estática dos procedimentos.
* **Node.js:** Utilizado para criar um ambiente de desenvolvimento robusto e para integração de serviços de backend.
* **API do Google:** Explorada durante a imersão para ampliar o projeto com recursos de Inteligência Artificial e/ou busca avançada (como a **API Gemini**), demonstrando a capacidade de gerar conteúdo dinâmico.

## 🚀 Como Executar o Projeto

Este é um projeto estático e não requer instalação de pacotes ou frameworks.

1.  **Clone o Repositório:**
    ```bash
    git clone [SUA URL DO REPOSITÓRIO]
    ```

2.  **Abra o Arquivo:**
    Navegue até a pasta do projeto e simplesmente abra o arquivo `index.html` em seu navegador web (Chrome, Firefox, Edge, etc.).

    ```bash
    cd guia-primeiros-socorros
    open index.html 
    ```

## 📂 Estrutura de Arquivos

* `index.html`: Contém a estrutura da página (Home, Header, Footer, Modal).
* `style.css`: Contém toda a estilização e a definição da paleta de cores.
* `script.js`: Contém toda a lógica de busca, filtro, manipulação de layout e modal.
* `data.json`: Armazena os dados dos procedimentos (nome, descrição, links, contato, etc.).
